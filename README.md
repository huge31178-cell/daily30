# 每日30条热点新闻（个人新闻索引网站）

适配手机和电脑的单页网站。分成「中国热点 / 全球热点 / 中国娱乐」三栏，每栏**最多**10条。点击新闻可打开原媒体报道；可将完整日报导出为一张PNG长图。

## 如何获得固定网址（GitHub Pages，免费）

1. 登录 GitHub，创建一个 **Public** 仓库，例如 `daily30`（不要勾选自动生成README）。
2. 将本压缩包**解压后**的所有文件和文件夹，上传到仓库根目录；确保 `.github/workflows/deploy.yml` 也上传。
3. 仓库顶部 `Settings` → 左侧 `Pages` → `Build and deployment` → `Source` 选择 `GitHub Actions`。
4. 进入 `Actions` → `每日新闻更新与网站发布` → `Run workflow`，启动第一次更新与部署。完成后会在 Pages 设置里显示网址。
5. 以后直接在浏览器打开 `https://你的用户名.github.io/daily30/`，每天看更新的新闻。

默认在北京时间09:00触发自动采集和网站发布；GitHub定时任务有可能延迟，并非保证09:00整发布。可在Actions手动点 `Run workflow` 立即重新抓取。

## 新闻如何收集

- 中国热点：中国新闻网要闻、时政、社会、财经、即时频道。
- 全球热点：中国新闻网国际、BBC World、BBC Business。
- 中国娱乐：新浪娱乐要闻、焦点、明星，中国新闻网文娱频道。
- **全部仅展示原媒体的标题、来源、时间和原文链接；不转载全文。**
- 只选近24小时带发布时间的RSS文章。对部分相似标题去重，用时效、频道、关键词进行简单排序。此排名**不是全网真实热搜排名**，也不保证十大事件齐全。
- 来源有时可能限流、改网址或缺失发布时间。若某类不足10条，网站会真实显示不足，不会编造/补旧闻。
- 个别全球新闻是英文标题，本站**不自动伪造中文翻译**。日后可以加入经过人工审校的机器翻译。
- 任何公共展示或商业化运营，应单独核查内容源的授权条件；本模板旨在个人阅读索引。

## 本地测试

电脑装有Python 3.9+时，运行：

```bash
python update_news.py
python -m http.server 8080
```

然后访问 `http://localhost:8080/`。RSS抓取需要外网访问权限，部分源可能失败。

## 定制说明

- `update_news.py`：RSS来源、24小时范围、标题去重/简单排序；可自行追加来源。
- `index.html` `style.css` `app.js`：网站样式、分类、搜索、长图导出。
- `data.json`：每日运行时生成。预置的是**空示例**，不是伪造新闻。
- `.github/workflows/deploy.yml`：GitHub每天定时更新和部署。
