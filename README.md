# 每日30条热点新闻 · 第三版

这是一份**全中文的个人新闻阅读索引**，不是新闻机构，也不是权威热搜榜。网站把“中国十大热点、全球十大热点、中国十大娱乐”分成三个栏目，每天更新，并保存历史日报。点新闻标题可跳转到报道链接。

## 第三版更新说明

**1. 更像「每天60秒读懂世界」的选题原则。** 重要政策、经济民生、社会热点和国内外重大事件具有较高优先级；校园招聘、一般性展览、普通文化活动等边缘消息降权。兼顾几个主题，避免某类新闻占满十条。

**2. 引入上游精选日报作为对照参考。** 每天读取 `vikiboss/60s-static-host` 提供的同日期公开 JSON 数据。匹配到与原始新闻报道相似的主题时，提高其入选机会；但**不会直接把整个精选日报复制到本站**，不会因为它被精选就断言事实正确。每条本站新闻仍保留媒体报道标题、链接、时间。上游每日数据通常在北京时间上午10点之前更新，如不可用则自动回退到媒体新闻订阅源筛选。

**3. 全球栏目优先中文标题，所有网站界面中文化。** 全球新闻允许英文新闻源参与发现和计算热度，但呈现在网站上的新闻标题必须是中文媒体标题，**不依赖无法验证的自动翻译**。常见外媒名称会显示为中文；未找到官方中文译名的媒体统一标为「海外媒体」并在数据中保留英文原名，便于回查。英文-only新闻可能因此无法上榜，不能保证完全涵盖国际新闻。

**4. 中国娱乐单独筛选。** 电影、电视剧、综艺、明星和音乐优先，一般博物馆、考古、地方艺术展等不当作娱乐热搜。暂未接入微博热搜历史数据，因此仍然不是权威热度榜。

**5. 每日固定截稿和历史存档。** 统计窗口为前一天北京时间09:00至当天09:00。自动任务每天北京时间09:20尝试发布；若当日精选日报尚未发布，10:20会再次尝试补充精选参考。GitHub Actions定时任务可能延迟。每次成功采集保存 `history/YYYY-MM-DD.json`，已保存的旧日期不会被覆盖；当天尚未获取精选参考的早期快照允许同日更新一次。此前旧版保存的日报会保留原貌，旧版未存档的日期不能自动完整恢复。

## 从第二版升级（你的仓库）

仓库地址：`https://github.com/huge31178-cell/daily30`

网站网址：`https://huge31178-cell.github.io/daily30/`

1. 解压新的 `daily30_v3_upgrade.zip`，将根目录的以下文件复制到 GitHub 仓库根目录，**替换同名文件**：
   - `index.html`
   - `app.js`
   - `style.css`
   - `update_news.py`
   - `README.md`
2. 还需要将 `.github/workflows/deploy.yml` **覆盖原位置的同名文件**。注意不能新建一个根目录 `deploy.yml`。浏览器上传不能覆盖时，请打开 GitHub 原文件，点击铅笔编辑，替换成新版内容并提交。

5. 检查最新工作流是否为绿色对勾，然后打开网站，按 `Ctrl + F5` 强制刷新。

## 排名机制与局限

候选主要来自新闻媒体和新闻聚合的**新闻订阅源**，先筛选过去24小时报道，再进行相似标题去重。评分来自：

- **精选参考信号**：当天精选日报提及并与媒体报道标题匹配的新闻增加权重。
- **重大事件关键词**：重大政策、民生、社会事件、国际局势等优先。
- **媒体覆盖度**：不同新闻机构提及同一事件会加分；同一机构不同订阅源不重复计数。
- **新闻主题均衡**：避免十条都来自一类消息。
- **时效性**：作为较低权重因素，不让新鲜但普通的新闻压过重要事件。

这仍然只是**启发式排序**。不同媒体对同一新闻的写法不一致，可能无法自动聚成同一事件；订阅源不全、部分新闻发布时间在截稿线外、媒体并未提供完整公开订阅等情况，都可能造成遗漏。多媒体转发**不等于事实已被独立核实**。对重要或有争议的消息，请点击标题查看媒体原始报道并交叉核验。

## 如何本地检查

```bash
python -m unittest discover -s tests -v
python update_news.py
python -m http.server 8080
```

更新脚本采用 Python 标准库，不需要配置 AI 接口密钥。可在本地浏览器打开 `http://localhost:8080/`。本地运行新闻采集需要可用网络，网络不可用时不能判断线上来源是否正常。
